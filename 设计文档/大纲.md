# 设计大纲

## 项目功能

- 设备模型的创建, 编辑, 删除
- 设备的创建, 编辑, 删除, 查看
- 设备数据的实时监控与历史数据查询

### 设备模型

1. 创建设备模板
    - 网关模型
      - 功能: 平台数据交换, 下发指令和采集子设备属性
    - 属性:
        - 协议: Modbus, MQTT, HTTP, TCP, UDP等
        - 连接信息: 目标服务器IP地址, 端口
        - 注册包: 是否开启, 发送方式(连接后发送, 每次发送消息前发送等), 注册包内容
        - 心跳配置: 是否开启, 心跳间隔, 心跳内容等
        - 数据采集配置: 采集间隔, 采集内容等
    - 子设备模型 
      - 功能: 接收网关下发的指令, 被动上报数据
      - 属性:
        - 从机号
        - 寄存器
          - 起始地址
          - 数据类型: 整数, 浮点数, 字符串等
          - 长度
          - 单位
          - 描述
    - 独立设备模型: TODO
2. 编辑设备模板
3. 删除设备模板
